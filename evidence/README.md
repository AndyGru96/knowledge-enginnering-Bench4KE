# A2 prompt example

The `a2_p1_example` directory contains one complete Domain-OntoGen P1 task. It includes the assembled task prompt, task metadata, status, and the request and response files for both competency-question calls.

The task metadata contains a P0 value in its `prompt_hash` field, while the saved prompt and both request files contain the P1 suffix. The copied task files are unmodified.

The complete generation archive is stored separately from this repository:

- A1 archive: 2,243 files, 41,602,395 bytes;
- A2 archive: 4,663 files, 82,263,585 bytes.

The repository also includes `results/a2_prompt_task_verification.csv` and `results/a2_prompt_verification_summary.json`, which summarize the checks performed across all 102 A2 tasks.
